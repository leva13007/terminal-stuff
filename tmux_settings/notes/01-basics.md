# 01 — Basics

Sessions, windows, panes — базові поняття tmux, до того як лізти в конфіг (`02-config.md`) і плагіни (`03-plugins.md`).

---

## Що таке tmux

tmux — terminal multiplexer: один термінал, всередині якого можна тримати багато сесій, вікон і панелей, які живуть незалежно від конкретного вікна терміналу. Закрив термінал / відпав SSH — процес всередині tmux продовжує працювати, можна підключитись назад.

Ієрархія:

```
session
 └── window (вкладка)
      └── pane (панель всередині вкладки)
```

---

## Prefix

Майже всі команди tmux викликаються через **prefix + клавіша**. Дефолтний prefix — `Ctrl+b` (в цьому конфізі не перевизначений, див. `config/tmux.conf`).

Тобто `prefix + c` означає: натиснути `Ctrl+b`, відпустити, потім натиснути `c`.

---

## sessions

Сесія — контейнер для вікон. Зазвичай одна сесія = один проєкт/контекст.

```bash
tmux new -s myproject      # створити сесію з назвою
tmux ls                    # список сесій
tmux attach -t myproject   # підключитись до сесії
tmux kill-session -t myproject
```

Всередині tmux:

| команда | що робить |
|---------|-----------|
| `prefix + d` | detach — вийти з сесії, не завершуючи її |
| `prefix + s` | список сесій, перемикання |
| `prefix + $` | перейменувати поточну сесію |

Detach — ключова фішка: сесія лишається живою у фоні, можна відключитись і підключитись пізніше (навіть з іншого термінала/SSH).

---

## windows

Вікно — як вкладка в браузері, всередині сесії. Нумерація починається з `1` (`base-index 1` в конфізі, дефолт tmux — `0`).

| команда | що робить |
|---------|-----------|
| `prefix + c` | нове вікно |
| `prefix + ,` | перейменувати поточне вікно |
| `prefix + n` / `prefix + p` | наступне / попереднє вікно |
| `prefix + 1..9` | перейти на вікно за номером |
| `prefix + w` | список вікон, перемикання |
| `prefix + &` | закрити поточне вікно (з підтвердженням) |

---

## panes

Панель — розділення вікна на частини. В цьому конфізі splits перевизначені (див. `02-config.md`):

```
bind h split-window -h   # Ctrl+b h → панель праворуч
bind v split-window -v   # Ctrl+b v → панель знизу
```

Дефолтні (без ремапу) — `prefix + %` (вертикальний split) і `prefix + "` (горизонтальний) — легко переплутати саме тому в конфізі і зроблено простіший `h`/`v`.

| команда | що робить |
|---------|-----------|
| `prefix + o` | перейти на наступну панель |
| `prefix + ←↑→↓` | перейти на панель у напрямку стрілки |
| `prefix + z` | zoom — розгорнути панель на все вікно (ще раз — повернути назад) |
| `prefix + x` | закрити поточну панель (з підтвердженням) |
| `prefix + q` | показати номери панелей на екрані |

З `mouse on` (див. `02-config.md`) панелі можна перемикати й ресайзити просто мишкою.
