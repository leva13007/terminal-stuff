# 02 — Config explained

Розбір поточного `config/tmux.conf` — що робить кожна строка і навіщо.

---

## Mouse

```
set -g mouse on
```

Вмикає підтримку миші: скролінг, клік по панелям для фокусу, ресайз панелей перетягуванням бордера.

`-g` (global) — застосовується до всіх сесій і вікон.

### Чому виділення мишкою "зникає"

Симптом: тягнеш мишкою по тексту, підсвітка з'являється — і за мить сама зникає, ніби нічого не виділилось.

Це нормальна поведінка, не баг. З `mouse on` виділення мишкою обробляє **сам tmux**, а не термінал: під час drag tmux малює виділення через свій copy-mode, а щойно відпускаєш кнопку — одразу копіює виділене у **внутрішній tmux-буфер** і виходить з copy-mode. Підсвітка гасне саме в момент відпускання — і оскільки скопійоване лежить у tmux-буфері, а не в системному clipboard macOS, `Cmd+V` в іншій програмі нічого не вставляє.

### "Обхідний" модифікатор — ненадійний спосіб

Класична порада — тримати модифікатор під час drag, щоб термінал обробив виділення сам, в обхід tmux mouse-mode. Але поведінка відрізняється між терміналами:

- **iTerm2** — `Option`, задокументована й настроювана фіча (Preferences → Profiles → Keys), курсор навіть візуально змінюється на text-selection поки Option затиснутий;
- **Terminal.app** (стандартний macOS) — `Option` не працює взагалі: курсор не змінюється, тобто про цей модифікатор термінал просто не знає. Підтверджено на двох різних машинах, тобто це не збіг, а системна відмінність від iTerm2.

Тобто "правильного модифікатора на всі випадки" не існує — покладатись на це ненадійно, особливо якщо доводиться пересідати між iTerm2 і Terminal.app.

### Рішення, які працюють незалежно від терміналу

```
bind-key -T copy-mode-vi MouseDragEnd1Pane send-keys -X copy-pipe-and-cancel "pbcopy"
bind-key -T copy-mode     MouseDragEnd1Pane send-keys -X copy-pipe-and-cancel "pbcopy"

bind m set -g mouse \; display "mouse: #{?mouse,on,off}"
```

| рішення | коли використовувати |
|---|---|
| `copy-pipe-and-cancel "pbcopy"` | звичайне повсякденне виділення мишкою — тепер саме копіювання йде в системний clipboard macOS, а не тільки в tmux-буфер. Підсвітка все одно зникне на mouse-up (це нормально) — головне що `Cmd+V` тепер реально вставляє |
| `prefix + m` | коли треба гарантоване нативне виділення терміналом (наприклад в Terminal.app, де bypass-модифікатор не працює) — вимикає `mouse` на льоту, виділяєш звичайним drag як у будь-якому терміналі без tmux, вмикаєш назад `prefix + m` |
| `prefix + [` → `v` → `y` (copy-mode, вбудовано, без додаткового конфігу) | найнадійніший спосіб — виділення клавіатурою, взагалі не залежить від миші чи терміналу |

`copy-pipe-and-cancel` — те саме що `copy-selection-and-cancel` (дефолтна дія tmux на mouse-up), тільки додатково пропускає виділене через shell-команду (`pbcopy`) перед тим як вийти з copy-mode.

## Splits (розділення вікна на панелі)

```
bind h split-window -h
bind v split-window -v
```

`bind` — прив'язка клавіші до команди. Викликається через **prefix + клавіша** (default prefix: `Ctrl+b`).

| команда | що робить |
|---------|-----------|
| `split-window -h` | горизонтальний split — нова панель **праворуч** |
| `split-window -v` | вертикальний split — нова панель **знизу** |

Тобто: `Ctrl+b h` → панель праворуч, `Ctrl+b v` → панель знизу.

> Назви `-h` / `-v` плутають: `-h` = horizontal divider (вертикальна лінія), `-v` = vertical divider (горизонтальна лінія). Простіше запам'ятати через результат: `h` → поряд, `v` → під.

## Перезавантаження конфігу

```
bind r source-file ~/.tmux.conf \; display "Config reloaded!"
```

`Ctrl+b r` — перечитує конфіг без перезапуску tmux. `\;` — розділювач команд в tmux (дозволяє виконати дві команди разом). `display` — показує повідомлення в status bar.

## Base index

```
set -g base-index 1
```

Вікна починають нумеруватись з `1` замість `0`. Зручніше — цифри `1–9` на клавіатурі зліва направо відповідають вікнам.

## Layouts

```
Ctrl+b Space
```

Перемикає між вбудованими раскладками панелей по колу:

| layout | опис |
|--------|------|
| `even-horizontal` | всі панелі в ряд, однакова ширина |
| `even-vertical` | всі панелі стовпцем, однакова висота |
| `main-horizontal` | одна велика зверху, решта знизу в ряд |
| `main-vertical` | одна велика зліва, решта праворуч стовпцем |
| `tiled` | автоматична сітка, намагається зробити всі рівними |

Зручно коли панелей багато і хочеш швидко переорганізувати — не треба нічого налаштовувати вручну.

## Pane titles

```
set -g pane-border-status top
set -g pane-border-format " #{pane_title} "
```

`pane-border-status top` — показує рядок-заголовок зверху кожної панелі.

`pane-border-format` — формат цього рядка. `#{pane_title}` — змінна tmux, яка містить заголовок панелі.

Заголовок встановлюється з шелу через функцію `tp` (див. `config/zshrc-additions.zsh`):

```zsh
function tp() { printf '\033]2;%s\033\\' "$1"; }
```

`\033]2;...\033\\` — це **OSC 2** escape-послідовність (Operating System Command). Термінал (і tmux) перехоплює її і записує рядок як заголовок панелі.

Використання:
```bash
tp "my-server"   # → pane title стає "my-server"
```
